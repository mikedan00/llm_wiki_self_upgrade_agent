# LLM Wiki Rules

1. 원본 자료는 `data/sources`에 보관하고 수정하지 않는다.
2. LLM이 정리한 문서는 `data/wiki`에 저장한다.
3. 장기 기억은 `data/memory`에 저장한다.
4. 작업 실행 기록은 `data/runs`에 저장한다.
5. 자기개선 제안은 `data/upgrades`에 저장한다.
6. 학습 데이터는 `data/training`에 JSONL로 저장한다.
7. Obsidian 호환성을 위해 관련 문서는 `[[문서명]]` 링크로 연결한다.
8. 확실하지 않은 정보에는 `불확실:` 표시를 붙인다.
9. 코드/배포/오류 해결 문서는 증상, 원인, 해결, 검증, 다음 작업 순서로 정리한다.
10. 모델 자체 학습은 별도 LoRA/SFT 파이프라인으로 분리한다.
